Operator portraits, named by operator id from `js/operators.js` (`ash.webp`, `jager.webp`, ...).
They're 400px-wide WebP renders with transparent backgrounds, from the
[Rainbow Six Siege fan wiki](https://rainbowsix.fandom.com). The artwork belongs to Ubisoft.

To add or replace one, save it here as `<operator id>.webp`. Any operator without an image
shows a colored card with their initials instead.
